Acme Browser

About

Acme browser is not for everybody, possibly nobody.

Written in python you can easily open it and look at the code.
It can do lots of things a browser like Chrome and Firefox can do, but not everything.
There is zero "information gathering" code and it has an ad blocker.
It uses the WebKit2 python module as do many of the popular browsers.
